# GrowthPilot

**캠페인 준비의 반복 작업을 없앤 AI CRM 워크스페이스**

타깃 찾기 → 캠페인 작성 → 발송 검수 → 승인 → 발송 → 성과 분석 → 다음 실험

- 조건은 한 번만 입력
- 명단은 옮기지 않음
- 발송 가능 인원은 자동 계산
- 결과는 다음 캠페인으로 연결

> 합성 데이터 데모 · 실제 메시지 발송 없음

## 문제

**"60일 넘게 안 산 VIP에게 재구매 쿠폰 발송"**

| 기존 방식 | 반복되는 일 |
| --- | --- |
| 분석가에게 명단 요청 | 조건 설명, 대기 |
| 캠페인 도구 설정 | 같은 조건 재입력 |
| 발송 전 확인 | 동의·연락처·발송 이력 시트 대조 |
| 승인 요청 | 숫자·조건 메일로 복사 |
| 결과 보고 | 발송·클릭·구매 데이터 수작업 결합 |
| A/B 판단 | 수치가 높은 쪽을 감으로 선택 |

각 단계는 쉽지만, **단계 사이에서 같은 정보를 옮기고 다시 확인하는 일**이 반복됨

## 해결

| 단계 | 기존 | GrowthPilot |
| --- | --- | --- |
| 타깃 | 요청 → 대기 | 조건 선택 또는 질문 → 즉시 확인 |
| 대상 연결 | 재입력 | 저장한 세그먼트 선택 |
| 문구 | 직접 작성 | AI 초안 자동 입력 |
| 발송 확인 | 시트 대조 | 검수 버튼 1회 |
| 승인 | 메일 | 화면에서 승인 |
| 성과 | 수작업 결합 | 자동 집계 |
| 다음 실험 | 새로 기획 | 재실험 초안 생성 |

검수·승인은 유지, **그 사이의 옮기기·재입력·대조만 제거**

## 핵심 기능

### 1. 발송 가능 인원 자동 계산

세그먼트 284명 → 검수 → **발송 가능 247명**

| 제외 사유 | 인원 |
| --- | ---: |
| 탈퇴 | 6 |
| 수신 미동의 | 12 |
| 연락처 없음 | 4 |
| 이미 받은 고객 | 3 |
| 발송 한도 초과 | 12 |

- 줄어든 이유를 사유별로 확인
- 쿠폰 만료·금지 문구 → 발송 차단

### 2. AI 문구 초안

대상 · 혜택 · 말투 선택 → A/B 초안 → 폼 자동 입력 → 수정 후 저장

| | A안 (혜택) | B안 (관계) |
| --- | --- | --- |
| 제목 | 다시 고르는 즐거움, 15% 쿠폰과 함께 | 그동안 잘 지내셨어요? |
| 본문 | 15% 할인 쿠폰으로 마음에 드는 걸 골라보세요. | 오랜만이에요. 15% 할인 쿠폰으로 편하게 둘러보세요. |

- "15% 할인" → 통과
- "20% 할인" → 입력과 다른 숫자, 자동 재생성
- "오늘까지만" → 없는 조건, 자동 재생성

### 3. 승인한 그대로 발송

- 승인 후 수신 거부 → 발송 직전 자동 제외
- 검수 후 문구 수정 → 재검수 필요
- 발송 버튼 두 번 클릭 → 1회만 발송
- 세그먼트 조건 변경 → 기존 캠페인 대상 유지

### 4. 감이 아닌 근거로 A/B 판단

A안 3.27% vs B안 2.15% → 수치상 A 우세 → 표본 부족 → **승자 확정 불가, 재실험 권장**

- 통계적으로 확실할 때만 승자 표시
- 수신거부가 늘어난 안은 승자 제외
- 결과 화면 · 리포트 · CSV 같은 숫자

### 5. 결과 → 다음 캠페인

완료 캠페인 → AI 분석 → 재실험 초안 → 저장

- 확인된 수치
- 검증할 가설
- 해석의 한계
- 다음 행동

### 6. 대화로 이어가는 AI 어시스턴트

- "60일 넘게 안 산 VIP 찾아줘" → 대상 수 → 세그먼트 저장
- "이 세그먼트로 캠페인 만들어줘" → 이어서 진행
- "전환율 높은 캠페인 3개 비교해줘" → 비교 표

## AI 원칙

| AI | 시스템 · 사람 |
| --- | --- |
| 요청 해석 | 숫자 계산 |
| 문구 초안 | 저장 결정 |
| 성과 해석 | 승인 · 발송 |

AI가 숫자를 만들거나 확인 없이 저장하는 경로는 없음

## 사용 흐름

1. **Segments** 휴면 VIP 조건 → 저장
2. **Campaigns** 세그먼트 선택 → AI 초안 → 저장
3. **검수·승인** 제외 사유 확인 → 승인
4. **발송·결과** 모의 발송 → 반응·전환 확인
5. **Experiments** A/B 판정
6. **AI 분석** 재실험 초안 저장

조건 재입력 0회 · 명단 다운로드 0회

## 범위

- 합성 데이터, 실제 발송 없음
- 로그인 없는 공개 데모
- A/B 판정 기준은 시연용으로 완화
- 업무 시간 절감률은 미측정
