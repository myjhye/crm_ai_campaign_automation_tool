# Overview 화면 재구성

Overview는 데이터셋 이름·원천 건수, 4개 KPI(전체·활성·신규 고객·재구매율), 고객 상태 분포와 행동 퍼널로 구성한다. 계산 규칙은 지표의 툴팁에 두고, 기간·기준 시점과 미제공 기능은 하단의 작은 안내로 표시한다. 비교값이 없으면 비교 문구를 생략하고, 재구매율 분모가 없으면 `—`로 표시한다. 미제공 지표를 KPI 카드로 만들지 않는다.

`components/chart.js`의 공통 가로 막대 컴포넌트는 HTML 표의 한 행에 라벨·막대·숫자를 함께 표시한다. 최대값을 100%로 정규화하고 0값은 폭 0으로 표시한다. 별도 SVG와 중복 표는 제거했다. 고객 상태 라벨은 기존 고객 조회로 연결되고, 같은 컴포넌트를 Data 화면의 원천 분포에도 사용한다.

AI 패널은 HTML부터 숨겨 초기 화면 깜빡임 없이 접힌 상태로 시작한다. 상단 버튼으로 펼치거나 접을 수 있다. 데스크톱에는 KPI 4개를 가로로 배치하고 작은 화면에서는 줄을 나눈다.

새 샘플은 `체험용 소형 샘플`·`체험용 전체 샘플`로 생성한다. `003d`는 이름이 정확히 `Demo small / seed 42` 또는 `Demo demo / seed 42`이고 DEMO·ANALYSIS·version=1인 기존 기본 데이터만 한국어로 변경한다. 충돌 검사용 version을 증가시킨다. 편집된 이름과 version 2 이상은 유지하며, downgrade로 사용자 이름을 되돌리지 않는다. 이 동작은 앞선 데이터셋 진입 문서의 “기존 이름 유지” 정책에서 사용자가 허용한 기본 이름 두 개에 대한 예외다.

회귀 검증: 막대 정규화(100·50·25·0, 전체 0), 비교 문구, 브라우저의 실제 픽셀 폭 비율과 0px, KPI 카드 4개, AI 기본 접힘·펼침, 모바일 가로 넘침, 기존 사용자 편집 이름 보존.
