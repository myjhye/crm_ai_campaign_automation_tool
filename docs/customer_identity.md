# 고객 이름과 목록 표시

새 샘플의 이름은 `scripts/data/korean_names.py`의 성 40개와 이름 부분 목록에서 SHA-256(seed + external_id)로 조합한다. 같은 seed와 ID에는 항상 같은 이름을 만들며 실명 자료를 사용하지 않는다. 합성 이름이 실존 인물의 이름과 우연히 같을 수는 있다.

기존 코드의 시나리오 문자열은 external_id가 아닌 name에 저장되어 있었다. 실제 external_id는 `customer-95` 형태이며 주문·이벤트 참조와 함께 유지한다. 시나리오 그룹은 생성기의 `GROUPS[고객 번호 % 10]`으로 확인한다. 기존 데이터는 재실행해도 덮어쓰지 않는다. 새 이름을 보려면 `--dataset-key korean-names` 등 새 키로 샘플을 생성한다.

목록은 이름 / 상태 / 이메일 / 구매 합계 / 주문 수 / 최근 구매 순서다. 외부 ID와 시나리오 순번은 목록에서 숨기고, 이름이 비어 있으면 “이름 미등록”으로 표시한다. 외부 ID는 상세 화면에서 확인한다. 이메일 미등록 및 고객 상태는 색상과 텍스트를 함께 표시한다. 기본 선택 위젯의 옵션 색상 지원은 OS와 브라우저에 따라 다르므로 텍스트 라벨도 유지한다. 계산 규칙은 열 제목의 정보 아이콘으로 옮겼다. 필터 적용 시 동일 기간의 무필터 고객 총수를 함께 조회하여 표시한다.

기존 샘플의 이름 소급 적용은 `python -m scripts.backfill_demo_names --dataset-id UUID`로 먼저 건수를 확인하고 `--apply`로 반영한다. seed·size·dataset-key로 생성 UUID를 검증하며 기본값은 42·small·default다. 빈 이름, 외부 ID와 같은 이름, 생성기의 기존 시나리오 이름만 변경한다. 사용자 편집 이름과 주문·이벤트는 유지하며 데이터 버전과 감사 기록을 같은 트랜잭션에서 남긴다. 재실행은 변경 0건이다.

가입일 정렬은 서버가 날짜와 ID로 안정적으로 처리한다. 기존 샘플은 모든 고객 가입일이 같아 날짜 정렬 효과가 보이지 않았다. 서로 다른 날짜의 PostgreSQL fixture로 오름차순·내림차순을 검증하며 동률은 ID 순서로 처리한다.
